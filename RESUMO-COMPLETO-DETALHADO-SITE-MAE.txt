SEÇÃO: CLAUDE CODE
────────────────────────────────────────────────────────────────────────────────
Conteúdo:
  • Título: "Claude Code"

  Tabela de variáveis:
    VARIABLE              | VALUE
    ANTHROPIC_BASE_URL    | https://ghostcli.dev
    ANTHROPIC_API_KEY     | gcli_...

  • Aviso importante: "ANTHROPIC_BASE_URL never ends in /v1. The SDK appends /v1/messages on its own, so pointing at …/v1 hits /v1/v1/messages and returns 404 — and the CLI complains about an 'issue with the selected model', blaming the model for a URL mistake."

  Tabs: PowerShell | cmd | bash / zsh

  Exemplo PowerShell:
    $env:ANTHROPIC_BASE_URL = "https://ghostcli.dev"
    $env:ANTHROPIC_API_KEY  = "gcli_..."
    claude --model claude-fable-5.1

  • Nota: "With the variables in your environment, every claude command talks to GhostCLI — no extra flag and no config file."

SEÇÃO: CODEX CLI
────────────────────────────────────────────────────────────────────────────────
Conteúdo:
  • Título: "Codex CLI"
  • Subtítulo: "Claude in Codex, step by step"

  Passo 1: "Prepare API access"
    "In the dashboard, check your plan, activate the API add-on, create your key and authorize your IP using the email code. This authorizes its provider network (ASN), so IP changes within the same ASN do not require another approval. A chat subscription alone does not enable API access."

  Passo 2: "Open the Codex configuration"
    "Use ~/.codex/config.toml on macOS/Linux or %USERPROFILE%\.codex\config.toml on Windows. Create the directory and file if missing. Back up existing settings; merge the example without duplicating entries. If CODEX_HOME is customized, use its config.toml."

  Passo 3: "Select GhostCLI and a Claude model"
    "Put model and model_provider at the top, before any [table]. The provider name must match [model_providers.ghostcli]. GhostCLI translates the Responses API used by Codex to the selected model. This does not make Claude an OpenAI model."

  Passo 4: "Set your key and start a new session"
    "Copy the environment command from the generator. For permanent Windows variables, open a new terminal. Start codex in your project. Use /status to inspect the selected model; try a simple prompt before a larger task."

  • Aviso: "Use the exact model ID from the catalog. Model availability follows your plan. Keep /v1 in the Codex URL and wire_api = 'responses'. Do not use the Anthropic /v1/messages endpoint in Codex."

  • Nota sobre erro: "If Codex warns 'Model metadata not found' or writes files through shell commands, download the catalog setup below, run node codex-setup.mjs and start a new Codex session."

  Botões: "Download Codex catalog setup" | "Open configuration generator" | "Official Codex provider documentation"

  • Aviso TOML: "Codex ignores OPENAI_BASE_URL for the default provider: it needs its own provider in config.toml"

  Exemplo config.toml:
    model = "claude-sonnet-5"
    model_provider = "ghostcli"
    [model_providers.ghostcli]
    name = "GhostCLI"
    base_url = "https://ghostcli.dev/v1"
    env_key = "GHOSTCLI_API_KEY"
    wire_api = "responses"

  • Aviso: "Order matters in TOML: model and model_provider must come before [model_providers.ghostcli]. After the table, the parser reads them as keys of that table and Codex silently falls back to the OpenAI provider."

  Exemplo PowerShell:
    $env:GHOSTCLI_API_KEY = "gcli_..."
    codex

  • Nota: "The variable name is whatever you set in env_key. To switch models, change model at the top of the file."

SEÇÃO: SDK AND cURL
────────────────────────────────────────────────────────────────────────────────
Conteúdo:
  • Título: "SDK and cURL"
  • Descrição: "The two SDKs use opposite conventions: with OpenAI the base_url includes /v1; with Anthropic it does not — the SDK appends the path itself."

  Tabs: Python | Node | cURL — Anthropic | cURL — OpenAI | cURL — Gemini

  Exemplo Python (OpenAI SDK):

  • Link: "or follow the written steps"

  Step 2: "Put it on the PATH"
    "The installer places the executable in ~/.local/bin. If your terminal does not recognise the claude command, that path is not on your PATH."

    Tabs: PowerShell | bash | zsh

    Exemplo PowerShell:
      $claude = "$env:USERPROFILE\.local\bin"
      $atual  = [Environment]::GetEnvironmentVariable("Path", "User")
      if ($atual -notlike "*$claude*") {
      [Environment]::SetEnvironmentVariable("Path", "$atual;$claude", "User")
      }

    Nota: "Close the terminal completely and open a new one for the PATH to take effect."

  Step 3: "Point it at GhostCLI"
    "Set the environment variables and run claude. If it asks whether to use the detected key, confirm."

    Tabs: PowerShell | bash / zsh | permanente (bash)

    Exemplo PowerShell:
      [Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://ghostcli.dev", "User")
      [Environment]::SetEnvironmentVariable("ANTHROPIC_API_KEY", "gcli_...", "User")
      [Environment]::SetEnvironmentVariable("ANTHROPIC_MODEL", "claude-opus-5", "User")
      # feche o PowerShell e abra de novo, depois:
      claude

    Aviso: "The URL here goes WITHOUT /v1. The CLI appends /v1/messages itself — with /v1 in the variable the request becomes /v1/v1/messages and fails."

  Step 4: "Check that it applied"
    Tabs: PowerShell | bash / zsh

    Exemplo:
      echo $env:ANTHROPIC_BASE_URL
